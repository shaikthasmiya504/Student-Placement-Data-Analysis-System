# Student Placement Data Analysis System

## Project Description
This project analyzes student placement data using Python and SQLite. It generates reports and charts to understand placement statistics.

## Technologies Used
- Python
- SQLite
- Pandas
- NumPy
- Matplotlib

## Features
- Student placement eligibility analysis
- Placement statistics
- Average package calculation
- Duplicate offer handling
- Data visualization
- Placement reports

## Project Structure
- student_placement_data_analysis – Main Python code
- reports – Generated reports
- placement.db – SQLite database

## How to Run
1. Download the project.
2. Install required libraries:
   pip install -r student_placement_data_analysis/requirements.txt
3. Run main.py.
